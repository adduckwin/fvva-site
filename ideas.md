## Идея 1: «Скандинавский минимализм встречает терапевтическое пространство»

**Design Movement**: Scandinavian Minimalism / Japandi

**Core Principles**:
- Чистота и простор — много воздуха, минимум визуального шума
- Природные текстуры — льняные, бумажные, каменные фактуры
- Функциональная красота — каждый элемент несёт смысл
- Тёплый минимализм — не холодный, а уютный

**Color Philosophy**: Палитра вдохновлена утренним туманом и тёплым деревом. Основа — тёплый белый (#F8F6F3) с акцентами тёплого шалфея (#8B9D83) и глубокого графита (#2C2C2C). Цвета передают ощущение безопасности и покоя.

**Layout Paradigm**: Асимметричная сетка с большими полями. Текст выровнен по левому краю с широкими отступами справа. Фотографии выходят за рамки контейнера, создавая динамику.

**Signature Elements**:
- Тонкие горизонтальные линии-разделители
- Мягкие тени с большим blur
- Органические формы (blob shapes) как фоновые акценты

**Interaction Philosophy**: Плавные, неспешные переходы. Элементы появляются мягко, как вдох. Hover-эффекты — лёгкое смещение и изменение прозрачности.

**Animation**: Fade-in при скролле с задержкой 100ms между элементами. Параллакс на фоновых элементах. Плавное раскрытие текста.

**Typography System**: DM Serif Display для заголовков (элегантная антиква), Nunito Sans для основного текста (мягкая, дружелюбная гротеска).

## Идея 2: «Терапевтический журнал — Editorial Design»

**Design Movement**: Editorial / Magazine Layout

**Core Principles**:
- Типографика как главный инструмент — крупные заголовки, контрастные размеры
- Журнальная вёрстка — колонки, врезки, цитаты
- Визуальная иерархия через масштаб
- Содержательность — текст и образы работают вместе

**Color Philosophy**: Глубокий тёмно-зелёный (#1A3C34) как цвет доверия и стабильности, кремовый (#FDF8F0) для фона, тёплый терракотовый (#C4785B) для акцентов. Палитра вызывает ассоциации с кабинетом психолога — книги, кожа, тёплый свет.

**Layout Paradigm**: Многоколоночная вёрстка, вдохновлённая журналами. Большие типографические блоки чередуются с изображениями. Сетка 12 колонок с нестандартным распределением.

**Signature Elements**:
- Крупные буквицы (drop caps) в начале статей
- Горизонтальные полосы-акценты терракотового цвета
- Фотографии с мягким наложением (overlay) зелёного тона

**Interaction Philosophy**: Элементы раскрываются как страницы книги. Hover на карточках — лёгкий подъём с тенью. Тесты раскрываются пошагово.

**Animation**: Staggered появление элементов. Плавный скролл между секциями. Подчёркивание ссылок анимируется слева направо.

**Typography System**: Playfair Display для заголовков (классическая элегантность), Source Sans 3 для основного текста (чистая читаемость).

## Идея 3: «Мягкий неоморфизм — Цифровое пространство заботы»

**Design Movement**: Soft Neomorphism / Organic UI

**Core Principles**:
- Мягкость форм — скруглённые углы, плавные переходы
- Тактильность — элементы выглядят «нажимаемыми»
- Слоистость — элементы на разных уровнях глубины
- Эмоциональная теплота через цвет и свет

**Color Philosophy**: Нежный лавандовый фон (#F0EBF8) с акцентами глубокого индиго (#4A3F6B) и мягкого розового (#E8B4B8). Палитра передаёт спокойствие, интроспекцию и надежду.

**Layout Paradigm**: Карточная система с «парящими» элементами. Центральная колонка с боковыми акцентами. Секции разделены мягкими волнистыми SVG-формами.

**Signature Elements**:
- Неоморфные карточки с двойной тенью (свет и тень)
- Градиентные иконки
- Волнистые разделители между секциями

**Interaction Philosophy**: Элементы «вдавливаются» при нажатии. Карточки мягко приподнимаются при наведении. Формы тестов — пошаговый wizard.

**Animation**: Spring-анимации для появления элементов. Мягкий bounce при взаимодействии. Градиентные переливы на фоне.

**Typography System**: Cormorant Garamond для заголовков (утончённая классика), Nunito для основного текста (округлая, дружелюбная).

## Выбранный подход: Идея 2 — «Терапевтический журнал — Editorial Design»

Этот подход лучше всего подходит для сайта психолога, потому что:
1. Журнальная вёрстка идеально подходит для блога и статей — ключевого контента сайта
2. Глубокий зелёный цвет ассоциируется с доверием, стабильностью и профессионализмом
3. Типографическая иерархия помогает структурировать большой объём текста (тесты, статьи)
4. Editorial-стиль выглядит серьёзно и профессионально, но не холодно
